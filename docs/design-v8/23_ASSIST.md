# CASHLY V8 — PILLAR 5: ASSIST, AI CO-PILOT & VOICE OPERATOR

## 1. Intent: Grounded Financial Intelligence Layer

Assist (`InsightsPage.tsx`, `AIChatbot.tsx`, `VoiceCallModal.tsx`) is **not a generic AI chatbot**. It is an autonomous financial operator grounded in the user's real database.

Every insight adheres to the canonical formula:
```
OBSERVATION ──► WHY IT MATTERS ──► FINANCIAL IMPACT ──► DIRECT PRODUCT ACTION
```

---

## 2. Telemetry Architecture

1. **Active Telemetry Cards:**
   - Financial Health Pulse
   - Identified Savings Room
   - Active Insights
   - Weekly Habits Progress (`0 / 3 Habits completed this week`)
2. **Weekly Financial Coach:**
   - Concrete behavioral tasks generated from active spending patterns (e.g., "Limit dining out to 2 evenings this week").
3. **Co-Pilot Operator Panel:**
   - Live conversational assistant with direct deep links (e.g. `[Review Inbox] ↗`, `[Adjust Dining Budget] ↗`).
4. **Voice Call Modal:**
   - Full-duplex voice synthesis and audio wave visualization for hands-free financial queries.
