# CASHLY V8 — SETTINGS & IDENTITY WORKSPACE

## 1. Intent: Executive Control Center

Settings (`SettingsPage.tsx`) preserves the comprehensive V7 six-zone architecture while integrating into the V8 Sovereign Pine Teal design system.

The six functional zones:
1. **Account & Identity:** User avatar, name, email, account ID copy button.
2. **Interface & Currency:** Base currency selection, theme toggle, sound effects switch.
3. **AI & Automation:** Autonomous habit suggestions, auto-categorization sensitivity.
4. **Security & Sessions:** Active session audit, biometric/passkey settings, password updates.
5. **Data & Privacy:** Complete export of transaction history (JSON/CSV), cloud backup sync.
6. **Danger Zone:** Controlled workspace reset and account deletion with strict modal confirmation.

## 2. Profile Page (`ProfilePage.tsx`)

Identity-focused personal summary featuring:
- User avatar with Pine Teal accent.
- Account verification status.
