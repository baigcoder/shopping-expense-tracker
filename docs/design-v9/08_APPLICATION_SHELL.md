# CASHLY V9 — 08 APPLICATION SHELL
## Navigation Rail, Status Sentinel & Command Surface

### 1. Minimal Vertical Rail Architecture

The Cashly V9 application shell abandons heavy bubble navigation in favor of a precision vertical architectural rail:
- Width: `68px` collapsed, `240px` expanded with smooth ease.
- Midnight surface styling (`#09141B` / `#101E25`) providing a constant, stable anchor on desktop.
- Five Canonical Pillars mapped cleanly:
  1. **Home**: Primary Financial Canvas (`/dashboard`)
  2. **Activity**: Operational Ledger & Inbox (`/transactions`)
  3. **Plan**: Budget, Commitments & Goals Desk (`/budgets`)
  4. **Analyze**: Deep Financial Modeling & Money Twin (`/analytics` & `/money-twin`)
  5. **Assist**: Autonomous AI Co-Pilot & Voice Dispatch (`/insights`)
- Real-time inbox badge indicating unapproved pending transactions in Amber.

### 2. Universal Top Command Bar

- Minimal 52px hairline bar with fluid search / command bar (`⌘K` hotkey indicator).
- Active pillar indicator with breadcrumb context.
- System sentinel indicator: "Real-time Sync Active", active currency selector, and profile quick toggle.
