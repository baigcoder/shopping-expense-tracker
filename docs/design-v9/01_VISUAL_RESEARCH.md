### 2. The Anti-Card Mandate

Traditional web apps default to card grids because they are easy to scaffold. In fintech, however, excessive cards fragment financial narratives:
1. **Broken Causality**: Money is an interconnected flow (Income → Commitments → Discretionary → Savings → Investments). Dividing these into 4 separate floating boxes obscures their mathematical relationship.
2. **Visual Clutter**: Every card requires 4 borders, 4 corner radii, and padding, consuming 40% of screen real estate in redundant margins.
3. **Template Monotony**: When every section has the same 3-column card grid, user engagement collapses.

**The V9 Rule**: Containers are permitted *only* when real semantic encapsulation or physical elevation is required (e.g., credit cards, popovers, actionable dialogs). The default structure is **Canvas → Data → Context → Action**.
