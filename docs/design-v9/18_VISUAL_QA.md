# CASHLY V9 — 18 VISUAL QA PROTOCOL
## Verification Matrix & Forensic Quality Gates

### 1. Mandatory Screen Review Checklist

Every surface must pass the following forensic criteria:
1. **Anti-Repetition Gate**: Confirm that no three identical card layouts appear consecutively.
2. **Tabular Numerals**: Confirm `tabular-nums` is active on all currency amounts, avoiding glyph shift.
3. **Contrast Gate**: All text combinations meet WCAG 2.2 AA (minimum 4.5:1 for regular text, 3:1 for large display).
4. **Semantic Color Integrity**: Confirm that Sovereign Jade is strictly brand/CTA, Green is positive inflow, Amber is sentinel alert, and Violet is AI.
5. **Zero Overflow**: Confirm horizontal scrolling only occurs on intended data tables.
6. **Focus Rings**: Keyboard navigation shows crisp 2px sovereign jade outline with 2px offset.
