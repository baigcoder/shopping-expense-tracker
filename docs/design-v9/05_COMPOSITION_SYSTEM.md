# CASHLY V9 — 05 COMPOSITION SYSTEM
## Eliminating the Card Grid: Canvas, Data, Context, Action

### 1. The Compositional Shift

Cashly V9 rejects the generic formula of repeating 3-card or 4-card grids. Every screen is organized as a dynamic **Financial Surface** using continuous planes, architectural dividers, asymmetric data anchors, and progressive side sheets.

```
       OLD MODEL (Card-First)                  NEW V9 MODEL (Canvas-First)
```

### 2. Core Compositional Archetypes

1. **Split Editorial Surface**:
   - Hero and Auth pages employ an intentional 45/55 or 50/50 horizontal split between high-typography context and an active, living workspace canvas.
2. **Dense Financial Ledger (Activity & Review)**:
   - Full-width tabular canvas with hairline column separators. Transactions are line items with crisp tabular numbers, status rings, and immediate inline triage, not cards.
3. **The Financial Planning Desk (Plan)**:
   - Horizontal velocity ribbons showing committed obligations, discretionary headroom, and savings runway in unified mathematical continuity.
4. **The Full-Width Trajectory Canvas (Money Twin & Analyze)**:
   - Dark mode instrument theater. High-contrast line graphs with safe/risk confidence bands, timeline scrubber, and dynamic scenario sliders directly beneath the curve.
5. **Contextual Action Side-Sheet**:
   - Deep inspection and item modification occur in sliding right-hand architectural sheets that maintain continuous visibility of the underlying data canvas.
