# 05 — TYPOGRAPHY SPECIFICATION (LANDING V10)

### 1. Typeface Roles

| Typeface | Weights | Usage & Scope |
| :--- | :--- | :--- |
| **Syne** | 700, 800 | Primary Display Typography: Monumental hero headlines, section statements, large balance amounts (`2768,71`), and step counters. |
| **Space Grotesk** | 500, 600, 700 | Secondary Structural Typography: Navigation links, metadata pills, card tags, subheaders, and button labels. |
| **Inter** | 400, 500, 600 | Body & Functional UI Typography: Transaction descriptions, body explanations, chart axis labels, and tabular numeric ledgers. |
