# 04 — COLOR SYSTEM SPECIFICATION (LANDING V10)

### 1. Primary Palette Tokens

| Token Name | Hex Code | Role & Psychological Trigger |
| :--- | :--- | :--- |
| `--landing-orange` | `#EE5024` | Primary brand accent; cadmium warmth, energetic focal blocks, and primary CTAs. |
| `--landing-pink` | `#F0A1CB` | Soft candy electric pink; analytical dashboards, statistics panels, and highlights. |
| `--landing-pink-light` | `#F8C3DE` | Subtle tinted backing for product cards and translucent overlays. |
| `--landing-sage` | `#BBC7B1` | Natural earthy olive-sage; security architectures, activity logs, and grounding panels. |
| `--landing-burgundy` | `#80383D` | Deep chocolate wine; recurring commitment blocks, predictive forecasting fields, and high-value metrics. |
| `--landing-ink` | `#111111` | Deep obsidian black; primary typography, dark product canvases, and high-contrast night modes. |
| `--landing-cream` | `#F4F3EE` | Warm studio canvas; avoids harsh clinical `#FFFFFF` page backgrounds and provides photographic warmth. |
| `--landing-white` | `#FFFFFF` | Crisp surface highlights, floating navigation pills, and ledger containers. |
| `--landing-border` | `#E5E4DE` | Hairline definition rules, status separators, and subtle outer outlines. |

### 2. Functional Application Rules
- **Color as Architecture**: Do not sprinkle tiny rainbow dots. Use massive continuous color blocks.
- **High Contrast Readability**: White text on Cadmium Orange (`#EE5024`), Deep Ink (`#111111`), and Burgundy (`#80383D`). Deep Ink text on Candy Pink (`#F0A1CB`), Sage (`#BBC7B1`), and Warm Ivory (`#F4F3EE`). All combinations surpass WCAG 2.2 AA contrast standards.
