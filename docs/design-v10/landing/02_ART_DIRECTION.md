# 02 — ART DIRECTION & CAMPAIGN LANGUAGE (LANDING V10)
## Cashly: The Editorial Financial Operating System

### 1. Vision Statement
Cashly V10 is an editorial, product-led financial showcase. It is built as a digital campaign poster where the software is treated as an oversized, tangible object. The interface rejects standard enterprise dashboard templates in favor of high-energy color blocking, monumental typography, and deliberate asymmetry.

---

### 2. Core Pillars of the Art Direction

| Principle | Execution in Cashly V10 |
| :--- | :--- |
| **Architectural Tangibility** | Interfaces have physical presence. Cards use 44px radii on mobile frames, 24px on desktop canvases, subtle contact elevation, and authentic micro-chrome. |
| **Monumental Typography** | Headlines span up to 72px–88px on desktop using `Syne` (800 weight), demanding visual attention and setting an assertive editorial voice. |
| **Strategic Color Blocking** | Monolithic color regions (Cadmium Orange, Candy Pink, Sage, Wine, Deep Ink) create immediate visual pacing and distinguish distinct product capabilities. |
| **Product as Hero** | Software interfaces occupy 50%–65% of screen compositions. No abstract illustrations or generic placeholder mockups. |
| **Rhythmic Variation** | Every consecutive section shifts structure: Campaign Hero → 3-Panel Triptych → Sticky Lifecycle → Asymmetric Split → Interactive Sandbox → Climax Block. |

---

### 3. Voice & Tone
- **Authoritative, not bureaucratic**: "FINANCE IS OUR EXPERTISE.", "SEE WHAT YOUR MONEY IS DOING.", "KNOW WHAT COMES NEXT."
- **Concrete, not vague**: Numbers are formatted in tabular currency (`Rs 42,870`, `2768,71 USD`, `42 days`).
- **Review-first**: The user is always in sovereign control of their canonical ledger.
