# CASHLY — PILLAR 5: ASSIST (EMBEDDED CO-PILOT) (V5)

**Classification:** Pillar Architecture & Screen Specifications (Authority #23)  
**Primary Route:** `/insights` (or `/assist`)  
**Core Purpose:** Actionable financial co-pilot that executes decisions rather than reciting chat trivia.  

---

## 1. Assist Hub Architecture

1. **Live Context Telemetry:** Live Net Headroom, pending review count, top burn velocity category.
2. **Weekly Coach Plan:** 3 concrete financial tasks tailored to current week (e.g., *"Reduce Food Delivery by Rs 1,200"*, *"Review 3 Uncategorized Charges"*), with persistent completion checkboxes.
3. **High-Confidence Action Cards:** In-line action cards with direct deep-linked navigation buttons (`[Review 3 Items]`, `[Adjust Budget]`, `[Inspect Commitments]`).
4. **Embedded Operator Chat:** Context-grounded chat responding with clickable navigation chips.
5. **Voice Action Center:** Hands-free voice modal for spoken expense logging and ledger queries.
